🚀 ASAP 입고리스트 자동 생성

HTML 소스를 붙여넣어 입고리스트 엑셀 파일을 자동으로 생성하세요

📋 사용방법

  1. ASAP 사이트에서 상품 리스트 페이지를 엽니다.
  2. 브라우저에서 우클릭 → "페이지 소스 보기" (또는 Ctrl+U / Cmd+Option+U)를 선택합니다.
  3. 전체 HTML 소스를 복사(Ctrl+A, Ctrl+C)합니다.
  4. 아래 입력창에 붙여넣기(Ctrl+V)합니다.
  5. "입고리스트 만들기" 버튼을 클릭합니다.
  6. "다운로드" 버튼으로 엑셀 파일을 저장합니다.
💡 팁: 브라우저에서 Ctrl+U (Windows) 또는 Cmd+Option+U (Mac)를 눌러 페이지 소스를 빠르게 확인할 수 있습니다.
